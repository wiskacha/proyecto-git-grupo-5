# Veterinaria "El Ispi Feliz"

## Integrantes

- Viscarra Sergio
- Castellón Félix
- Escalera Kevin

## Descripción

Sitio web de la veterinaria "El Ispi Feliz", un espacio dedicado al cuidado y bienestar de las mascotas. Presenta los servicios de la clínica, información de contacto y un formulario para solicitar citas o realizar consultas, con un diseño amigable y una navegación sencilla.

## Tecnologías

- HTML
- CSS
- JavaScript

## Funcionalidades

- **Menú Interactivo con Scroll:** Header flotante con efecto de cristal difuso (_backdrop-filter_) al deslizar la página.
